## Задание

Посмотреть как работает сайт Monkeytype. Представлен макет приложения. Необходимо создать приложение-аналог.

## Требования:

1. У пользователя должен быть выбор режима теста скорости печати: на время или кол-во слов. В каждом из режимов должно работать изменение количества времени и символов.
2. Текст для печати можно брать из РыбаТекст, отправляя запрос и получая JSON или создать массив с разным текстом.
3. Если пользователь вводит символы верно, отображать их белым цветом, если неверно - подчеркивать и отображать красным цветом.
4. Если пользователь вводит лишние символы, в том чисте пробел, то отображать ошибки темно-красным цветом.
5. Если слово написано частично верно, подчеркивать слово и отображать ошибки красным цветом, верные символы - белым.
6. Кнопка “заново” начинает тест заново с тем же текстом и режимом. “Следующий тест” - начинает новый тест.
